# The Breve Hub — Booking Platform

Premium 50-seater conference & training hall booking site for Soundbank Media and Entertainment.

## Stack
- Next.js 15
- Tailwind CSS v4
- Supabase
- Paystack
- Vercel

## Dev
npm install
cp .env.example .env.local
npm run dev

## Admin
- Login: /login
- Dashboard: /admin
